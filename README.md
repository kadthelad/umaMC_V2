# UmaMC V2

## Projet en cours de développement

Ce projet est réalisé avec Astro, en utilisant HTML/CSS/JS.
Ce site web est une version améliorée de l'application [UmaMC V1](https://github.com/kadthelad/umaMC_V1).

Le site web est accessible sur [UmaMC](https://umamc.emerald-prism.fr/).

### Fonctionnalités:
- Insertion/Modfication/Suppression de données dans la base
- Visualisation des données

### Tester le projet:
- Aller sur le [site web](https://umamc.emerald-prism.fr/).
- Vous pouvez visualiser les données qui ont déjà été mise, mais vous ne pouvez pas modifier/supprimer/ajouter des données en tant que visiteur.
